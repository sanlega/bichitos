# Bichitos

Un terrario de bolsillo para iPhone: diseñas bichitos ridículos en pixel art, los sueltas en un mundo
y observas cómo se enamoran, se pelean, se persiguen y se escapan. Todo es procedural: el pixel art,
el comportamiento y la voz.
SwiftUI + SpriteKit, iOS 17+, sin dependencias de terceros.

- [docs/CONCEPT.md](docs/CONCEPT.md): el bichito, el motor de sprites, el mundo y el comportamiento
- [docs/DESIGN.md](docs/DESIGN.md): el sistema de diseño "Terrario"
